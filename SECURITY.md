# Security Policy

## Supported versions

Please check the latest released version when reporting a security issue. Maintainers will assess reports affecting older versions case by case.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [Backblaze's Bugcrowd program](https://bugcrowd.com/engagements/backblaze), as directed by the [Backblaze Trust Center](https://www.backblaze.com/company/trust-center). Do not open a public GitHub issue for a security report.

Include the affected version, a description of the issue, steps to reproduce it, and any relevant impact. Do not include credentials or other sensitive customer data.

Please allow time for the maintainers to investigate and coordinate a fix before disclosing the issue publicly. The security team can coordinate follow-up and disclosure through the reporting channel.
